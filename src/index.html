    WHY THE SOURCE MATTERS

    256 output bits can hide just 32 bits of possibilities. In the Milk Sad vulnerability, a faulty generator expanded a small starting state into long wallet secrets. A phrase can look random and pass its checksum while still being predictable. Read the original disclosure ↗

    03 / THE BITCOIN PATHS

    One seed. Different destinations.

    A derivation path tells a wallet which keys to use. These are common conventions; the words alone don’t identify which path your wallet used.

    Legacy BIP44m/44'/0'/0'/0/01… · P2PKH
    Nested SegWit BIP49m/49'/0'/0'/0/03… · P2SH-P2WPKH
    Native SegWit BIP84m/84'/0'/0'/0/0bc1q… · P2WPKH
    Taproot BIP86m/86'/0'/0'/0/0bc1p… · P2TR

    Examples above: mainnet, account 0, receiving address 0. An apostrophe marks hardened derivation. Testnet uses coin type 1'.

    Case and spaces matter. Every passphrase creates a different wallet; there’s no “incorrect passphrase” error. Unicode is normalized with NFKD.

    Standards, dependencies & limitations

    Based on BIP39, BIP32, BIP44, BIP49, BIP84, and BIP86. Statistical tests cannot certify a cryptographic generator: NIST SP 800-22. Checksum validity does not establish randomness or secrecy.

    English BIP39 only. Other formats, including native Electrum and SLIP39 phrases, are not assessed. This tool does not find balances, recover missing words, or sign transactions. It stores no session data and makes no runtime network requests. Following an external link or downloading from the hosted page is an explicit network action.
